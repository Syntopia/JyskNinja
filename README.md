# JYSK NINJA

[Play JYSK NINJA](https://syntopia.github.io/JyskNinja/)

![JYSK NINJA — Lantern Street](media/lantern-street.png)

- **Creation:** Blender, Codex, OpenAI image generation; characters via TRELLIS.2 / SkinTokens.
- **Software:** Three.js and meshoptimizer (MIT); SMAA and LTC shading ([notices](docs/CREDITS.md#software-and-derived-assets)).
- **Assets:** Quaternius animations and qubodup / StarNinjas / Independent.nu sounds (CC0); MediaPipe face topology (Apache-2.0); Yuji Boku font (OFL-1.1).
- **Audio:** Suno music (free plan; non-commercial); original voices generated with [Qwen3-TTS](https://huggingface.co/spaces/Qwen/Qwen3-TTS) (Apache-2.0 models).
